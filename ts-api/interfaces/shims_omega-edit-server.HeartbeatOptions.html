    Interface HeartbeatOptions

    Local compile-time contract for @omega-edit/server.

    The published package exposes generated declarations from packages/server/out, but a fresh monorepo checkout does not have those build artifacts yet. The client only needs a small surface from the server package at compile time, so we provide that contract here and keep the runtime import pointing at the real package name.
